Embed on any website
After installing, copy this snippet into your webpage.
<!-- RAG Chatbot Widget -->
<script
  src="http://localhost:8000/rag-widget.js"
  data-api-url="http://localhost:8000"
  data-api-key="YOUR_API_KEY"
  data-title="Ask my documents"
  data-theme="light"
  data-position="bottom-right">
</script>

Replace localhost:8000 with your server's IP or domain, and YOUR_API_KEY from Dashboard → API Key tab.

Frequently Asked Questions
Do I need programming skills?
No. The installer handles everything. The only requirement is Docker Desktop, which has a simple graphical installer.
Is my data safe? Does anything go to the cloud?
By default, all AI processing happens locally using Ollama. Your documents never leave your machine. If you choose to use OpenAI, your chat messages are sent to OpenAI's servers — but document storage remains local.
What file types can I upload?
Currently PDF files are supported. Support for Word documents and plain text files can be added in future versions.
Can multiple people use the same installation?
Yes. Each person registers their own account and gets a completely separate document store. Documents from one account are never mixed with another's.
What AI model does it use?
By default it uses phi3:mini (Microsoft, ~2 GB), a fast and capable small model. You can switch to llama3.2, mistral, or any model from ollama.com/library by editing one line in your .env file.
Can I run it on a server so others can access it?
Yes. Install Docker on any Linux VPS (DigitalOcean, Hetzner, etc.), run the same installer, and point your domain at port 8000. Remember to set ALLOWED_ORIGINS to your domain in .env.
How do I update to a newer version?
Run docker compose pull && docker compose up -d inside the folder where you installed it. Your documents and accounts are preserved.
